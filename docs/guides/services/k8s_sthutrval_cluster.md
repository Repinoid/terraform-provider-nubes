# Развёртывание Kubernetes: ограничения и предварительный чек-лист

> **Внимание:** перед началом развёртывания кластера Kubernetes убедитесь, что выполнены все описанные ниже условия. Несоблюдение порядка шагов может привести к ошибкам при создании кластера.

---

## Ограничения при развёртывании

| Ограничение | Статус |
|---|---|
| 1 кластер = 1 vDC | Действует (будет исправлено в ближайшее время) |

---

## Предварительный чек-лист

Перед установкой кластера Kubernetes необходимо последовательно выполнить следующие шаги.

### 1. Создать организацию в Cloud Director

- Перейдите в услугу **Организация в Cloud Director**.
- Создайте организацию.

### 2. Создать виртуальный датацентр (vDC)

- Перейдите в услугу **Виртуальный датацентр (vDC)**.
- Создайте vDC.
- Выделите **достаточно ресурсов для разворачивания _всех_ нод** кластера.

### 3. Создать Edge (сетевой шлюз периметра)

- Перейдите в услугу **Сетевой шлюз периметра (Edge)**.
- Создайте Edge.
- Обязательно:
  - Включить **ALB**.
  - Установить **Кол-во VS на AVI ≥ 3**.

### 4. Добавить внешние адреса в организации

- Вернитесь в **Организация в Cloud Director**.
- Выполните операцию **Modify**.
- Добавьте **3 внешних адреса**.
- Количество `ipSpaces` значения не имеет, важно чтобы суммарно было 3 адреса.

### 5. Настроить SNAT для виртуальных машин

- Вернитесь в **Сетевой шлюз периметра (Edge)**.
- Выполните операцию **Modify**.
- Выберите доступный `ipSpaceName`.
- Это будет **SNAT для виртуальных машин**.

### 6. Развернуть кластер Kubernetes

- Только **после выполнения всех шагов выше** переходите к услуге **Kubernetes кластер Штурвал**.
- Начните разворачивание кластера.

---

## Минимальные требования к кластеру

| Параметр | Значение |
|---|---|
| Мастер-ноды | минимум **1** |
| Воркер-ноды | минимум **1** |
| CPU (на ноду) | **4 vCPU** |
| RAM (на ноду) | **8 GB** |
| Диск (на ноду) | **50 GB** |
