> **Инструкция из личного кабинета**
> Это руководство по сервису из личного кабинета Nubes (ЛК). Текст приведён
> без изменений, «как есть».
>
Развертывает контейнер в k8s кластере с node, который можно использовать для запуска своих приложений.
Приложение должно быть доступно по ссылки в git репозитории, которая является входным параметром.
