# Terraform Provider Nubes

Install `repinoid/nubes` from the [Terraform Registry](https://registry.terraform.io/providers/repinoid/nubes/latest).

The provider manages resources in the Nubes PROD environment. See service guides, or use the [machine-readable provider schema](provider-schema.json).
